# nwanzegerald.me

Personal portfolio and resume site for Gerald Nwanze, built with React, TypeScript, Vite and Tailwind CSS.

## Development

```bash
npm install
npm run dev      # start the dev server
npm run build    # type-check and build for production
npm run lint     # run ESLint
npm run preview  # preview the production build
```

## Structure

- `src/Resume.tsx` — the single-page layout (hero, about, experience, projects, contact).
- `src/data.json` — all site content. Edit this file to update the intro, stacks, experience, projects and social links.
- `src/assets/dp.png` — profile picture.
